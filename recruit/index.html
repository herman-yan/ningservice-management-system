使用说明与已知限制

三步跑通

① 粘贴岗位 JD → 点「解析并生成规则」→ 在规则表里核对 / 调权重 / 设硬门槛；② 导入简历（官方导出 ZIP、单份文件或粘贴）；③ 看右侧排名、展开证据、打印或导出。

官方导出 ZIP（推荐路径）

在 BOSS 企业版「人才库 / 沟通中」勾选候选人 → 点【下载简历】→ 选 PDF，得到打包 ZIP；猎聘按套餐的简历下载额度同样可批量导出。把 ZIP 直接拖进左侧即可：自动展开逐个解析，支持中文（UTF-8 / GBK）文件名、嵌套压缩包，自动跳过目录、系统附带文件、加密与超限条目。平台导出的 CSV / JSON 结构化数据包会按行 / 按记录拆成多份候选人；含候选人字段表头的才拆，普通简历式 CSV 不会被误拆。
ZIP 全程用浏览器原生 DecompressionStream 解压，不引第三方库、不联网、不上传。加密压缩包（导出时设了密码）无法解析，会逐条提示；ZIP64 超大包与单份超 8MB 的条目会跳过，请在平台分批导出。

打分口径

硬门槛不满足 → 一票否决并归 0 分。其余规则按「完全命中 1.0 / 原文部分命中 0.6 / 未命中 0」乘权重，归一化到 0–100。简历未体现的项目按 0 分计入分母，但单列「待核实」并生成追问，不会写死成「不具备」。置信度= 可判定项权重占比，越低说明简历信息越缺。

已知限制

• 离线为纯关键词 + 同义词词典匹配，无语义理解，同义表述可能漏判，请在规则表补关键词。
• .zip / .docx 依赖浏览器原生 DecompressionStream（Chrome / Edge 103+）；不支持时请另存为 .txt。加密 ZIP、ZIP64、单份超 8MB 条目会被跳过并逐条提示。
• .pdf 需联网从 CDN 加载 pdf.js；离线状态请粘贴文本或转 .txt / .docx。ZIP 内 PDF 较多时逐份解析较慢，建议导出为文本格式。
• 图片简历 / 扫描件 不支持 OCR，需先转成文本。
• 中文简历版式自由，姓名 / 年限 / 学历可能识别不到，此时如实标注「未识别」而非猜测。
• 简历原文不写入 localStorage，仅 JD 与规则会本地保存以便下次打开。
